# Features and priorities

## P0 — launch

- Business profile and optional logo
- Customer profile
- Line items with quantity, unit price, optional discount
- Automatic totals in integer cents
- Optional tax (label, rate, inclusive/exclusive)
- Currency (default LKR)
- Quotation number, date, validity
- Notes, payment terms, delivery, terms
- Live preview
- Print and PDF
- Edit and reset
- Local auto-save and named drafts
- Validation and accessible labels

## P1 — next

- Multiple saved businesses
- Sinhala / Tamil UI
- Email a PDF from the user’s own mail client
- Quote status (draft / sent / accepted)
- Duplicate last quotation

## P2 — later

- Accounts and cloud sync
- Team templates
- Invoice conversion
- Public share links
- Usage analytics with consent
