# SEO implementation plan

## Current

- Descriptive titles and meta description in `index.html`
- Open Graph and Twitter tags
- JSON-LD `WebApplication`
- Semantic headings and internal links
- `robots.txt` and `sitemap.xml`
- Canonical tag (replace `https://example.com/` at deploy time)

## After a real domain exists

1. Set the canonical URL and sitemap host to the production domain.
2. Submit the sitemap in Google Search Console and Bing Webmaster Tools.
3. Keep title pattern: `QuoteCraft — {intent}`.
4. Target phrases: quotation generator Sri Lanka, LKR quotation PDF, free quote maker.
5. Avoid keyword stuffing and false claims (“IRD approved”, “legal invoice”).
6. Ensure Lighthouse accessibility and performance remain high; Core Web Vitals affect ranking.
7. Add an FAQ page with real questions only.
8. If you add a blog, write original guides (CCTV quotation example, contractor validity terms) instead of spun content.
